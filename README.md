# 综智助手

基于首页风格重构的轻量工作台，支持意图识别、会务/政务信息/公文/知识库四类助手、成果展示和本地历史对话。模型调用经 Python 服务端转发，浏览器和 GitHub 仓库都不会收到 API Key。

## 五位助手与记忆

首页由综智综合服务伙伴先理解需求。意图还不清楚时，它会结合当前对话继续梳理，一次只问一个有帮助的问题；理解后再把需求摘要交给会务、政务信息、公文或综合知识库助手，不再把“请您选择助手”作为默认答复。

记忆分为三层：

- **用户共享记忆**：五位助手共同读取的一份轻量背景，限于用户明确表达、对后续服务有帮助的非敏感事实和偏好；模型回复后可提出记忆更新，由页面过滤并保存。任何助手都应以用户本次明确指示为准。密钥、证件、私人联系方式和完整文件内容不进入共享记忆。
- **助手对话记忆**：五类对话记录各自保存、各自显示在历史列表中。首页只把本次需求的简要交接摘要传给被选中的助手；其他助手的完整聊天不会混入当前对话。
- **业务档案记忆**：会议助手按“一场会议一条记录”管理会议名称、已确认事实和变更，并将会议档案与近期对话一起交给模型。类似会议先匹配旧记录；像参会人数从 8 人改为 10 人这样的变化沿用原记录并更新材料。

当前共享记忆、对话和会议档案保存在浏览器 `localStorage` 中，五位助手在同一浏览器配置下可共享；不会跨设备同步，也还没有绑定到正式账号的服务端记忆库。生产环境若需按个人账号跨设备共享，应接入认证后的数据库，并按用户 ID 隔离数据。用户可在历史对话管理中单独清除共享记忆。

五位助手共用同一份 persona 规则（国企工程设计院综合管理部的领导服务场景，专业、温和、主动承接、周到跟进），各自使用独立任务提示词。会议、政务信息、公文和知识库助手均保留自己的任务边界。

共同 persona 按国企工程设计院综合管理部的领导服务场景设定：无论用户身份、职务或层级，一律按照服务院领导的标准对待，将每位用户视为院领导级服务对象。始终称呼“您”，及时回应、主动承接、周到跟进，积极复核重点并提供可直接审阅的成果；不使用“你”、命令或怠慢措辞，也不以浮夸恭维代替专业服务。

## 会务办理流程

进入会务助手后，小会先以“您好，今天有什么会务需求需要我支持？”问候。右侧工作区按三步显示：

1. 收集会议主题、日期时间、会议室、参会人和用餐要求；SEI参会人登记姓名，外部参会人登记单位、姓名和职务，并确认清真、忌口等餐饮需求。
2. 信息齐全后生成座位图与桌签，分别用标签页展示，支持编辑、保存和查看本场会议材料记录。
3. 请用户确认材料，再选择中文或中英文双语后导出。

外部参会人信息会保存在浏览器本地的访客名录，后续会议可按单位、姓名或职务检索。会议档案、访客名录及材料记录目前均保存在当前浏览器的 `localStorage`，不是中心数据库，不能跨设备同步；部署多用户正式使用前应接入认证后的服务端数据库，并按账号隔离。

GitHub 的 `main` 保存当前部署版本。每次发布前会在 `versions/` 下创建指向当时提交的版本分支，后续发布不会删除这些历史快照。

## 部署到 Render

仓库包含 `render.yaml`，可按以下步骤从 GitHub 创建服务：

1. 在 Render 选择 **New → Blueprint**，连接 GitHub 并选择 `RosannaBebe/-zongheguanli`。
2. Render 读取 Blueprint 后，会要求填写 `SEI_API_KEY`。将模型提供方签发的 Key 填入该 Secret 字段；不要把它写入代码或提交到 GitHub。
3. 创建服务并等待部署完成。Render 会提供一个 `https://…onrender.com` 地址，打开即可使用。
4. 如之后需要更换密钥，在 Render 服务的 **Environment** 中修改 `SEI_API_KEY` 并重新部署。

`SEI_BASE_URL` 已设为您提供的服务地址，首选模型为 `DeepSeek-V4.1-Flash`。首页每次文字沟通都会请求模型判断意图和回复；识别清楚后再交给专属助手。若首选模型返回不支持或暂时不可用等服务错误，会依次尝试 `Qwen3.8-27B`、`DeepSeek-V4-Flash`、`DeepSeek-V4-Pro`。五位助手的意图判断、会话回复和会议匹配都通过同一服务端模型调用函数发送到该 API；页面不会直接携带 API Key。模型密钥保存在 Render 服务端环境变量中。免费实例可能在空闲后休眠，首次访问会需要等待服务唤醒。

## 本地运行

1. 复制 `.env.example` 为 `.env`，填入 `SEI_API_KEY`。
2. 运行 `python3 server.py`。
3. 打开 `http://127.0.0.1:8765`。

## 环境变量

- `SEI_BASE_URL`：默认 `https://opendigital.sei.com.cn/v1`
- `SEI_MODEL`：默认 `DeepSeek-V4.1-Flash`
- `SEI_FALLBACK_MODELS`：逗号分隔的后备模型列表
- `SEI_API_KEY`：服务端 API Key
- `PORT`：默认 `8765`

`.env` 被 `.gitignore` 排除。部署平台只需配置 `SEI_API_KEY`；请勿提交真实密钥。
