# 综智助手

基于首页风格重构的轻量工作台，支持意图识别、会务/政务信息/公文/知识库四类助手、成果展示和本地历史对话。模型调用经 Python 服务端转发，API Key 由服务端保存。

## 五位助手与记忆

首页由综智综合服务伙伴先理解需求。意图还不清楚时，它会结合当前对话继续梳理，一次只问一个有帮助的问题；理解后再把需求摘要交给会务、政务信息、公文或综合知识库助手，不再把“请您选择助手”作为默认答复。

记忆分为三层：

- **用户共享记忆**：五位助手共同读取的一份轻量背景，限于用户明确表达、对后续服务有帮助的非敏感事实和偏好；模型回复后可提出记忆更新，由页面过滤并保存。任何助手都应以用户本次明确指示为准。密钥、证件、私人联系方式和完整文件内容不进入共享记忆。
- **助手对话记忆**：五类对话记录各自保存、各自显示在历史列表中。首页只把本次需求的简要交接摘要传给被选中的助手；其他助手的完整聊天不会混入当前对话。
- **业务档案记忆**：会议助手按“一场会议一条记录”管理会议名称、已确认事实和变更，并将会议档案与近期对话一起交给模型。类似会议先匹配旧记录；像参会人数从 8 人改为 10 人这样的变化沿用原记录并更新材料。

当前共享记忆、对话和会议档案保存在浏览器 `localStorage` 中，五位助手在同一浏览器配置下可共享；不会跨设备同步，也还没有绑定到正式账号的服务端记忆库。生产环境若需按个人账号跨设备共享，应接入认证后的数据库，并按用户 ID 隔离数据。用户可在历史对话管理中单独清除共享记忆。

首页与会务、政务信息、公文、综合知识库四个工作区统一由「赛博小潘」接待，共用一份角色设定。每个工作区加载自己的任务提示词，聊天记录按入口保存。

共同 persona 按国企工程设计院综合管理部的领导服务场景设定：无论用户身份、职务或层级，一律按照服务院领导的标准对待，将每位用户视为院领导级服务对象。始终称呼“您”，及时回应、主动承接、周到跟进，积极复核重点并提供可直接审阅的成果；不使用“你”、命令或怠慢措辞，也不以浮夸恭维代替专业服务。

## 会务办理流程

- **会议信息收集**：主题、时间和会议室，主办方与外部参会人，以及用餐和忌口分列为三项，支持任意顺序填写或通过聊天补齐。全部完成后确认开始制作。
- **材料制作**：顺序制作会议手册、会议名单、会议通知、座位图、桌签和就餐餐桌图。座位图暂用确定性的模拟排位。桌签制作前确认中文或中英文。不用餐时跳过餐桌图。
- **审阅与下载**：完成一份就显示该材料的标签页，可编辑和保存。制作期间的补充意见先暂停队列，处理或记录后再由用户确认继续。全部完成后可打包成一份 PDF 或 Word。
- **访客和材料库**：外部参会人的公司、姓名和职务进入访客库。各材料的生成稿和修改稿进入材料库，可按会议名和材料类型查阅并选为后续会议参考。库和档案保存在当前浏览器的 `localStorage`，无法跨设备同步。

GitHub 的 `main` 保存当前部署版本。每次发布前会在 `versions/` 下创建指向当时提交的版本分支，后续发布不会删除这些历史快照。

## 部署到 Render

仓库包含 `render.yaml`，可按以下步骤从 GitHub 创建服务：

1. 在 Render 选择 **New → Blueprint**，连接 GitHub 并选择 `RosannaBebe/-zongheguanli`。
2. Render 读取 Blueprint 后，会要求填写 `DEEPSEEK_API_KEY`。将模型提供方签发的 Key 填入该 Secret 字段；不要把它写入代码或提交到 GitHub。
3. 创建服务并等待部署完成。Render 会提供一个 `https://…onrender.com` 地址，打开即可使用。
4. 如之后需要更换密钥，在 Render 服务的 **Environment** 中修改 `DEEPSEEK_API_KEY` 并重新部署。

## 模型设置

打开页面右上角的模型设置，可新增、修改、删除、启用或停用 OpenAI 兼容的 Chat Completions 模型。URL 填接口基础地址，例如 `https://api.deepseek.com/v1`。首页对话及分流、四个业务助手的对话、会议匹配与材料生成使用当前浏览器启用的同一个模型。切换从下一次请求起生效。环境变量中的 DeepSeek 配置作为首次打开时的默认项。

自定义配置按浏览器保存到服务端 SQLite 文件，已保存的密钥不会回填到页面。部署后如需跨服务重启保留配置，请将 `MODEL_CONFIG_DB` 指向持久磁盘路径。公开部署的自定义接口使用可公开访问的 HTTPS 地址；本地访问支持本机 HTTP 模型接口。

## 本地运行

1. 复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`。
2. 运行 `python3 server.py`。
3. 打开 `http://127.0.0.1:8765`。

## 环境变量

- `DEEPSEEK_BASE_URL`：默认 `https://api.deepseek.com/v1`
- `DEEPSEEK_MODEL`：默认 `deepseek-flash`
- `DEEPSEEK_API_KEY`：服务端 API Key
- `MODEL_CONFIG_DB`：模型配置数据库路径，默认 `.model-config/profiles.sqlite3`
- `PORT`：默认 `8765`

`.env` 被 `.gitignore` 排除。部署平台只需配置 `DEEPSEEK_API_KEY`；请勿提交真实密钥。
